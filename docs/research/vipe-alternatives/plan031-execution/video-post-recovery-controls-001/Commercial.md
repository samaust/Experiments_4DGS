## Findings contract

`plan069-video-commercial-findings/v1` binds `candidate`, `source_revision`, `weights_revision`, `dependency_manifest`, named `author` and nonempty `scope`. `packages` contains exactly 48 rows with `name`, `version`, `permission: allowed`, nonempty `basis`, `installed_evidence` records from that package and `primary_evidence` entries `{url, record}`. Each URL is an HTTPS primary source and each retained record is verified. `embedded_components` uses the same evidence fields; package plus embedded rows must cover every notice derived from the complete installed inventory. `scopes` has exactly code, weights, dependencies and inference_outputs with explicit permission, basis and primary_evidence. Code includes evidence from the pinned native source closure. Findings remain review inputs rather than execution authority.

`plan069-video-commercial-independent-review/v1` requires status passed, a named distinct reviewer, exact assessment_template/dependency_manifest/permission_report/explicit_findings records and scope_permissions equal to allowed for all four scopes. Finalization reruns all preparation checks and verifies the deterministic report before producing `plan069-depth-commercial-assessment/v1`. The independent review remains the substantive permission decision.
