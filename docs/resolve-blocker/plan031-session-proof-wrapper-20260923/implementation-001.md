All `stop_group` callers were statically traced: supervisor final cleanup, the registered helper-fixture cleanup callback, the existing direct repeated-close test, and scenario-worker cleanup. The ledger branch requires the exact retained `Popen` object through `JOB_HANDLES[token] is process` and `id(process)` plus a bound root identity. It builds a complete local child-pidfd set and closes that local set if initial preparation fails, leaving the tree charged and without a published retry record. Once fully prepared, it publishes the pin map and explicit signal phase. It requires a post-wait empty group census before retiring descendants; a second empty census gates matching root retirement. A nonempty census is returned with the tree and pidfds charged. A same-handle retry validates retained pins, skips already retired descendants, acquires missing pins only for still-live descendants, and does not repeat a completed signal phase. A signal phase interrupted after it starts fails closed on retry. Pidfds remain open through durable root retirement, then close together. A second call on an already retired root checks the retired tree and empty group, waits the same object, and adds no signals or ledger transitions. The legacy no-ledger branch retains its former signal/group/wait/retire sequence. L35 may retain a separate pidfd while `stop_group` performs first tree retirement; its later terminal check accepts only an already-retired matching ledger identity and still polls its own retained descriptor before closing it.

The three findings from the first independent source review were addressed in the source and recognized as repaired in review 002: post-wait group census gates tree retirement; `root-retired.terminal` must equal the prior `root-wait.terminal` even when the final descendant triggers retirement; and descendant reservation requires a live B parent with matching boot ID, PID, start ticks, and PGID. The contract checks that full creator/root identity in the final ledger. If no such parent exists, reservation takes the separately charged root path or fails capacity admission.

The second independent source review found that the previous retry record was published before a complete pin set and that partial retirement closed descriptors too early. The revised pin map and signal-stage handling above address those cases in source. They await a third independent exact-source review and have no runtime clearance.
