Main saved the handle, sent `ABORT\n` to **that** session, and got exit1 with the driver's `explicit Main admission handoff required` error. No admission, launch note, exec-start, capture directory, or test followed. Diagnostic007 is retired; its identity request and preflight are historical, and index008 is the next candidate.

The likely immediate cause is reliance on a browser global in the `functions.exec` JavaScript isolate. A read-only isolate check returned `typeof btoa`, `TextEncoder`, `crypto`, and `performance` as `undefined`; `Date` and `JSON` are available. This explains the ReferenceError but does not establish which hashing or timestamp implementation the failed wrapper used beyond the named `btoa` call. Treat every untested global dependency as a launch risk. This is not evidence of a contract-source defect or a sandbox/permission denial.

Plan049 §7–§8, correction008 §3–§4, and `s1_validation_contract.py:437–530` require a disk-bound exact tool event: the returned `result` and actual `arguments` remain verbatim JSON objects; `output_sha256` is SHA256 of the returned output's exact UTF-8 bytes, including CR/LF; timestamps are UTC plus finite monotonic values in causal order. Event000 carries the actual positive integer handle; every later empty-input live poll uses and returns that same handle, and the final two polls have roles `pre_admission` and `at_admission`. The proof must bind strict path/byte/hash records for those contiguous events and the sole complete readiness line before admission. The historical diagnostic005 event000 (SHA256 `c6a88ef3c28475ed2522ca1446d14ca3b54391f3d7734ee53c918d65f8d547aa`) and proof (SHA256 `e7830a50ffa79cf6effca2c71dc1efef30841e0f88ecfc691356bcf6e5b29c63`) demonstrate the expected shapes, not reusable evidence.
