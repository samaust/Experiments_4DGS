# Comparison scope amendment 001 — segmentation and depth

## User instruction and precedence

The latest corrected user instruction is:

> I make a mistake. Remove Motion and Neighbors. Keep segmentation and depth.

This prospective amendment supersedes the earlier mistaken removal of depth and
neighbors, and any requirement to collect human comparisons of all four component
groups. The active human comparison and current viewer navigation contain
**segmentation (S) and depth (D) only**. Motion (M0–M2) and neighbors (N0–N2)
are excluded candidate package groups.

remains unchanged because actual packages bind its exact bytes. Apply this
separate scope amendment to active comparison navigation, review completion and
reporting; retain the original package hashes, media, reviews and decisions.
