## Proposed protocol remains REVIEW

A possible future bounded compatibility protocol would observe a representative
geometry edge, actual initializer conversion/storage, a few native updates and
checkpoint publication, fresh-process checkpoint reload and one rendered frame.

allocation ceilings and evidence checks still need independent review and human
approval. This document supplies neither those settings nor an executable native
probe. Small probes cannot establish full geometry coverage, 5,000-update endpoint
correctness, full schedule behavior, final checkpoint retention or production peak
memory. Measured storage adequacy needs a separate justified proof before DO.
