# S1 calibration correction and retry authority

The user authorizes planning, implementation, execution, result analysis,
correction and retries until S1 calibration succeeds. This prospectively
supersedes Proposal003's one-attempt limit and Proposal004's pending one-attempt
restriction. Historical approvals, requests, results and ledger events remain
unchanged; consumed identities are never replayed or retroactively accepted.

There is no numerical cap on fresh S1 calibration attempt identities. Each
attempt has a fresh immutable request, reviewed REVIEW/DO binding, current-source
passing qualification, live admission and finite3600-second deadline. The same
standing user authority covers subsequent attempts after a relevant diagnosed,
implemented and validated correction; no repeated unchanged failed command or
automatic immediate replay is permitted. Review and qualification may proceed
without requesting another user approval.

Root exclusively owns the single GPU. Preserve the existing original cumulative
ceilings:93600 GPU seconds,57600 CPU seconds and57600 setup seconds,22GiB device,
eight CPU workers,60GiB downloads and150GiB allocated artifacts. Preserve the
two-second sampling deadline,256KiB metadata limit, model/input/scientific pins,
ownership, cleanup and strict evidence contracts. No setup/download allocation,
reconstruction, unrelated experiment or final-render budget is added here.

Stop retrying when an accepted complete calibration succeeds, an existing budget
cannot admit the next bounded attempt, cleanup/ownership is uncertain, host access
is denied/unavailable, or indispensable input is missing. Diagnose unclear
failures before retrying. Preserve all failed results, exact charges and absent
terminal/poisoned-helper histories. A historical operational stop may be resolved
for a fresh identity only after confirmed cleanup and a reviewed validated fix;
the historical stop itself is retained.

For each unsuccessful attempt, record what failed, the relevant correction and
its validation. Independently review code changes, qualify complete current
source, recheck live assets/resources/ledger and create the next fresh identity
under this standing authority. Continue until success or a concrete remaining
blocker; local commits are checkpoints, not pauses.
