## Platform intervention and sequence

1. Preserve the existing records. Seek the Codex tool/session platform operator's authenticated correlation from the original diagnostic009 invocation (exact command, TTY and escalated request, failed outer wrapper call) to its native session. If the exact returned handle is recoverable, require the actual value, native session identity, terminal/liveness state and a documented supported route for Main to reattach or retire **that same session**. Do not contact it until an independent reviewer confirms binding and ownership. Recovery of a handle alone does not establish the driver or descendants' terminal state and does not authorize admission.
2. If handle recovery is unavailable, require platform-owned retirement of the correlated exact native session and its process-tree job, plus auditable terminal and descendant-retirement evidence. Verify independent host/job ownership and that no ambiguous descendant remains. This is a platform intervention on its own ownership records; this plan authorizes no PID-based action by Main. If neither route is supported, stop affected work, leave candidate009 charged and ask for the missing platform capability/evidence. No current attempt is claimed safely recoverable without that API evidence.
3. After C1/C2 independent PASS, mark candidate009's actual disposition without retroactively claiming a proof, admission or diagnostic. Its index, output paths and identity request remain consumed. Clear capacity only when the exact session/job and all descendants are proven retired. Recheck all original Plan049/054/055 gates before proposing any fresh index above the observed high-water. No candidate010, diagnostic, test, aggregate, start frame or `ADMIT` is authorized by this plan.
4. For a separately cleared future attempt, do all launch preflight outside the dedicated return-capture cell. Use the C3 order exactly, then inspect the original visible nested return and verify stored equality before any same-handle operation. A later cell may produce a value-preserving v2 event copy, write/read back and compare against the original. Every subsequent `write_stdin` must use that exact retained handle for start frame, both required live polls, `ADMIT\n`, terminal and retirement, under the adopted finite trust boundary and Plan055 PTY echo contract. If capture or comparison fails, stop and charge the new attempt; never guess or substitute identity.
