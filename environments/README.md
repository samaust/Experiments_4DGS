# Environment specifications

Use [the shared environment guide](../docs/environments.md) for commands and validation gates.

The target is standard CPython 3.14, uv, Torch 2.13.0+cu130,
torchvision 0.28.0+cu130, and the system CUDA 13.0 toolkit.
`constraints-cu130.txt` fixes the base ABI; `base-cu130.in` installs it.
Every research installation must use that constraint and `--torch-backend cu130`.
Torchaudio is intentionally omitted.

The method-named `.in` files are **unresolved candidate specifications**, not
complete upstream ports or tested locks. They separate Python dependencies from
source builds. `build.in` supplies extension build prerequisites.
`downloads.in` is independent of Torch. The browser and stdlib helpers need neither.

Resolve against the actual interpreter before installing. Audit upstream metadata
alongside these candidates: a successful candidate resolution is not proof that
the whole model resolves. Never bypass conflicting requirements with `--no-deps`
or overrides. Store resolution/build logs and provisional locks in `.local/`.
Only promote successfully resolved, reviewed locks to a tracked `environments/locks/`
directory, with interpreter/platform, uv version, source revisions and validation
status. No lockfiles are claimed or generated by this change.

Source dependency inventory to complete during porting:

| Environment | Sources whose full revisions and patches must be recorded |
| --- | --- |
| hust | HUST checkout, depth-diff-gaussian-rasterization, simple-knn; selected MMCV/config adapter |
| stg-render | STG checkout, bundled MMCV, ch9/ch3 rasterizers, forward_full/forward_lite, simple-knn |
| mango-render | Mango checkout, rasterizer, simple-knn, separately pinned PyTorch3D checkout |
| nopo4d | NoPo4D and Depth Anything 3; xFormers/gsplat source revisions if built from source |
| stg-colmap | STG preprocessing source and any native COLMAP CLI adaptation |

Submodule revisions come from `git submodule status --recursive`; record full
`git rev-parse HEAD` values in every independent source checkout. A moving Git
URL is not a reproducible source pin. Keep reusable port patches tracked under
`patches/`, not only inside ignored upstream checkouts.
